## Source And Implementation

- `inventory.json`: the live sitemap inventory.
- `source/`: dated browser captures of the actual page content, page metadata, links, images, and doctor/team modal biographies.
- `page-map.json`: source-to-destination mapping, aliases, and deferred form locations.
- `redirect-evidence.json`: observed legacy URL redirects.
- `images.json`: original image URL to local asset mapping.
- `src/data/pages.json` (from the repository root) is generated by `npm run content:import`. Imports are explicit; production builds never scrape the original site.

Imported wording, spelling, capitalization, prices, quotations, and links are preserved. This includes source heading casing under Bryan's explicit exact-copy direction. New shared UI labels follow the project's Title Case preference. Internal absolute links become local paths; external destinations, queries, fragments, telephone links, and email links are retained. Known aliases resolve locally and through Cloudflare's `_redirects` file.

Layout changes replace old WordPress/Elementor styles and executable code with shared Astro components. Profile biographies are visible on the page instead of hidden in modal dialogs. Repeated carousel clones and visual controls are removed; the original unique testimonials remain. FAQs remain readable without JavaScript. Decorative page backgrounds use the approved design; meaningful portraits and body photos are local assets.

`/review/` now holds the source patient-review content. The former internal homepage review moved to `/design-review/`. Both `/design-review/` and `/migration-review/` are noindex.

## Verification

Run:

```sh
npm run astro -- check
npm run build
npm run content:verify
npm test
```

`verify-migration.mjs` independently compares built HTML against the original snapshots, rather than comparing it to generated page data. The report in `verification.json` covers 43 pages, 1,391 source text segments, 185 original hyperlinks, and 92 media references. It also checks every built local link, anchor, and asset path. Exclusions are executable/theme markup, carousel duplicates/controls, replaced form implementations, and their blank AJAX iframes. The approved homepage is outside the verbatim migration comparison.

Browser checks cover all 43 pages at desktop width and 390px mobile width. Reports are in `browser-desktop.json` and `browser-mobile.json`. Representative page layouts were visually inspected, including services, profiles, contact, membership, sedation, campaign pages, and financing. The mobile menu navigates to the intended service and the original Contact Us alias redirects correctly. Cherry rendered its live widget; the responsive overflow found during testing was fixed.

The 11 existing Google-review endpoint tests pass. Astro development uses its static review fallback; the Cloudflare endpoint itself is not served by the Astro dev server.

The pages are ready for client review on the Cloudflare preview after the `main` deployment succeeds. Domain cutover, Jotform submission testing, preservation of the office-tour media, and final source-content decisions remain separate launch steps.
