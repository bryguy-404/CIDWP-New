## Copy and Capitalization

- Bryan prefers Title Case for headings, section titles, navigation/dropdown labels, service names, buttons, and other short UI labels: capitalize the first letter of each word (for example, "Meet Your Dentist" and "Problems We Treat").
- Write capitalization in the source text. Do not force headings or navigation to lowercase with CSS.
- Preserve names, brands, acronyms (such as CIDWP, HIPAA, DDS, and 3D), and contractions. Keep paragraphs, approved copy, and patient quotations in their original sentence case.
- This September 20, 2026 preference supersedes the lowercase-heading direction in the original Round 2 brief. Apply it to future website edits unless Bryan requests otherwise.

## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.
